Individual Project Site Plan

Site Name

Town Spy Investigators

This name was chosen because it reflects the investigative services and intelligence work the site will showcase. It is unique, memorable, and relevant to the project subject.

Site Purpose

The purpose of this site is to provide information about private investigation services, allow potential clients to explore offerings, and demonstrate my ability to build a dynamic, responsive website using HTML, CSS, and JavaScript. The site will also serve as a portfolio piece showcasing technical proficiency.

Scenarios

  • “How can I book an investigator for a case?”
  • “What services does Town Spy Investigators offer?”
  • “Where can I find contact information for consultation?”

Color Scheme

Primary: Dark Gray (#1a1a1a) for backgrounds and headers.
Accent: Red (#e74c3c) for buttons, highlights, and call‑to‑action elements.

Typography

Headings: Montserrat (modern, bold).
Body: Open Sans (clean, readable).
These fonts are applied directly in this document to demonstrate clarity and professionalism.

CSS Notes

A supporting CSS file will apply the chosen color scheme and typography. Styling will remain simple and consistent, focusing on accessibility and responsiveness.
